# Contributing to OASFuse

Thank you for helping make OpenAPI evolution safer.

## Development principles

- Keep comparisons deterministic and explainable.
- Treat every uploaded contract as untrusted input.
- Add a positive and negative test for each compatibility rule.
- Prefer focused changes with Conventional Commit messages.
- Run the relevant frontend and backend checks before opening a pull request.

## Pull requests

Describe the behavior changed, the rules affected, and the checks you ran. Never include real credentials or private API contracts in fixtures, screenshots, logs, or issue reports.

By participating, you agree to follow the repository's security guidance. A project license has not yet been selected; contributions should wait for the owner to confirm licensing terms.
